# Sistema visual

La evolución reutiliza el sistema existente: negro, amarillo `#F2D019`, cian `#00F0FF`, rojo de salida, Teko para titulares y Roboto Mono para lectura técnica.

## Reglas aplicadas

- No se generaron logos, iconos, SVG o assets visuales ficticios.
- Se reutilizaron imágenes locales con dimensiones confirmadas.
- El mundo, siluetas, cielo y composiciones protegidas permanecen.
- Los headers móviles usan nombres abreviados intencionales en lugar de texto cortado.
- Mission Tracker no se superpone a overlays.
- Credits ganó fondo oscuro suficiente para que controles del mundo no compitan visualmente.
- Capability Map conserva lenguaje diegético, pero explica conexiones profesionales reales.

Los ajustes de SVG del Prompt 1 permanecen: títulos únicos, `aria-hidden` en decorativos y sin IDs duplicados observados.
