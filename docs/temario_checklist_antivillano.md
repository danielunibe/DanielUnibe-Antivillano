# Temario y Checklist: Proyecto "Anti-Villano"

Este documento organiza la dirección creativa, estética, sonora y narrativa del proyecto "Anti-Villano" en un temario estructurado y un checklist por categorías para facilitar su desarrollo e implementación, basándose en el análisis previo.

---

## 1. Identidad Musical y Diseño Sonoro
> **Objetivo:** Convertir la canción en un tema icónico de personaje para videojuego/cine, manteniendo el contraste entre lo mecánico y lo humano.

- [ ] **Producción Base**
  - [ ] Confirmar tempo percibido (144 BPM o 72 BPM halftime).
  - [ ] Mantener pulso mecánico, bajo fuzz dominante y actitud seca.
- [ ] **Mejora del Coro (Drop)**
  - [ ] Simplificar la letra/idea del hook central.
  - [ ] Enfocar en una frase-icono (menos explicación, más impacto).
- [ ] **Teatralidad Cinematográfica (AAA)**
  - [ ] Aumentar el contraste entre los versos y el drop.
  - [ ] Añadir silencios agresivos (blackouts sonoros).
  - [ ] Incorporar golpes más grandes antes del drop.
  - [ ] Profundizar las capas graves.
  - [ ] Crear un motivo melódico (leitmotiv) reconocible.
- [ ] **Voz y Personaje**
  - [ ] Dar mayor carácter teatral o cínico a la voz.
  - [ ] Susurrar más en los versos; expandir en el coro.
  - [ ] Lograr tono de "villano cansado de actuar como villano".

## 2. Identidad Narrativa y Metáfora Central
> **Objetivo:** Definir la historia subyacente que justifica los elementos visuales y sonoros. El personaje no es un villano genérico, sino un error consciente dentro de un sistema.

- [ ] **Metáfora Principal**
  - [ ] Consolidar la columna vertebral conceptual: **Tinta + Máquina** (descartar el exceso de ideas compitiendo).
- [ ] **Objeto/Elemento de Poder (Tótem)**
  - [ ] Definir el objeto central que usa el personaje (Ej: Pluma metálica, tintero industrial, micrófono negro o interfaz de guion).
- [ ] **Conflicto Existencial**
  - [ ] Transmitir la negación de encajar en el "guion" de héroe o villano.

## 3. Dirección de Arte y Estética Visual (Industrial Noir)
> **Objetivo:** Crear un entorno que fusione fábrica, teatro oscuro y página en blanco corrupta.

- [ ] **Paleta de Colores**
  - [ ] **Negro:** Tinta, fondo, sombras, silueta.
  - [ ] **Blanco:** Papel sucio, flashes, planos de contraste.
  - [ ] **Magenta / Rojo oscuro:** Amenaza emocional.
  - [ ] **Azul frío:** Entorno industrial, tecnología, soledad.
  - [ ] **Dorado viejo (mínimo):** Mito, destino, "leyenda rota".
- [ ] **Composición e Iluminación**
  - [ ] Luz dura/cenital tipo interrogatorio o juicio.
  - [ ] Iluminación que recorta la silueta y separa al personaje del fondo.
  - [ ] El escenario reacciona al personaje (el entorno se deforma por la música).

## 4. Efectos Visuales (VFX) y Onomatopeyas
> **Objetivo:** Usar efectos no para decorar, sino para demostrar que la presencia del personaje altera y rompe la realidad/guion.

- [ ] **Tinta Viva**
  - [ ] Comportamiento inteligente (cables líquidos, humo denso, interfaz corrupta).
  - [ ] Reactividad al beat (bajo y voz).
- [ ] **Glitch Orgánico**
  - [ ] Frames desalineados tipo "papel mal impreso".
  - [ ] Sombras retrasadas o duplicación de siluetas.
  - [ ] Textos/interfaces que se corrompen o se tachan.
- [ ] **Tipografía Diegética / Onomatopeyas**
  - [ ] Palabras o frases del guion proyectadas en las paredes o entorno.
  - [ ] Textos que se rompen al compás de los golpes de batería (CLANK, ERROR).
  - [ ] Letras del escenario interactuando físicamente.

## 5. Estructura y Montaje de la Escena (Videoclip)
> **Objetivo:** Tratar el montaje como una pelea rítmica, usando cortes de cómic/videojuego y onomatopeyas sincronizadas.

- [ ] **Intro:**
  - [ ] Negro casi total. Gota de tinta vibrando con pulso mecánico.
- [ ] **Verso 1 (Identidad contenida):**
  - [ ] Plano medio frontal del personaje con el objeto tótem.
  - [ ] Sombra duplicada ligeramente retrasada.
- [ ] **Break / Pre-coro (Falla del sistema):**
  - [ ] Palabras proyectadas que se tachan solas.
  - [ ] Flashes blancos y cortes negros (blackouts).
- [ ] **Coro / Drop (Aceptación de anomalía):**
  - [ ] Explosión de tinta (alas, cables, corona incompleta).
  - [ ] Montaje agresivo, cortes rápidos al ritmo del bajo fuzz.
- [ ] **Verso 2 (Vulnerabilidad):**
  - [ ] Planos cerrados (mirada, detalles de manos/tinta).
  - [ ] Disminución de VFX, el espacio respira.
- [ ] **Outro (Marca final):**
  - [ ] Escenario vacío. Solo queda el símbolo, título o mancha.
  - [ ] Efecto de pantalla apagándose (máquina vieja).
