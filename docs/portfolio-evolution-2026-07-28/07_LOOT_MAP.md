# Loot Map

El mapa dejó de duplicar enlaces sociales sin verificar. Ahora representa cuatro nodos relacionados:

- Product Design
- UnibeLands 3
- Frontend Systems
- Contact Station

Cada nodo declara tipo, evidencia disponible, conexiones y una acción real hacia Stack, Projects o Contact. La selección usa botones de 44 px, `aria-pressed`, nombre accesible y feedback visual. El panel inferior explica la relación antes de navegar.

La vista móvil reserva espacio para el panel de detalle y oculta el Mission Tracker mientras el overlay está abierto. El acceso del mundo se verificó con Enter.
